# 显真文创工作室 · 团队协作系统

面向文创铸造、首饰与工艺品团队。v0.3采用黑灰底色、暖金点缀，支持电脑与手机，按「工时＋完成数量＋成果链接」记录投入，不作绩效排名。

## 运行与更新

需要 **Node.js 24.5或更高版本**，无第三方运行依赖，无需npm install。在项目文件夹执行 `npm start`，开发可用 `npm run dev`。

默认本机端口3000。Windows同Wi-Fi测试双击 `start-phone.cmd`；macOS/Linux执行 `sh start-phone.sh`。启动命令保留TLS校验，支持已有代理环境。

旧版请先停止服务，备份整个 `data` 文件夹，再完整复制到新版文件夹，与 `server.mjs` 同级。详见 [Windows更新说明](UPGRADE-WINDOWS.md)。不要删除原数据库或同时运行两个版本。

## 功能

- 项目与分类：最多五级，新增、移动、改名、停用与引用保护；文字、数字、下拉、必填、排序等项目字段，向后代分类继承。
- 任务看板：看板/列表、最多五级父子任务、紧急/高/普通/低优先级、可配置颜色、备注、参考链接、截止提醒、能力要求与分工建议。支持并行和前置依赖，不能形成循环。
- 协作与交接：多位协作成员、协作说明、讨论记录、多人交叉确认。子任务完成后才能完成父任务；全部确认后才完成交接。修改待确认任务的重要内容会清空旧确认，需要重新提交。
- 工作记录与经验库：项目问题、原因线索、处理措施、预防经验、类别、标签与状态；可筛选、规则整理或模型分析，保存来源与时间，需人工复核。
- 组织职能：预置产品企划、视觉设计、3D工艺、生产供应链、内容营销、电商运营、财务综合七类常见职能，允许跨部门兼岗；支持部门排序、部门总管/组长/组员、直属负责人、小组和组长、工种职能及个人能力标签。另预置店铺运营、投流、客服、摄影剪辑、直播、仓配和品控等可编辑职能。新成员可先选待定职能填写能力，再做岗位适配。
- 人员资料：姓名、昵称、简介、头像、工种、周参考工时与统筹职责。头像自动生成512像素方形缩略图并存入SQLite；保留初始五人名单与张宏浩统筹标记。
- 后台：分类、字段、流程、人员、工种、部门、小组、颜色标签与AI连接。保存后经SSE通知同一服务的所有页面，断线重连刷新数据。

## DeepSeek与规则建议

默认接口 `https://api.deepseek.com/v1`，模型 `deepseek-chat`。**当前开发实例没有模型密钥，没有执行真实模型调用。** 接口成功/失败处理用兼容响应自动测试，实际服务需配置后验证。

Windows可停止普通窗口后运行 `start-ai.cmd`，在本机隐藏输入API Key；不写入代码、仓库或数据库，仅本次运行有效。详见 [AI配置](AI-CONFIG.md)。此交互脚本未在实际Windows主机执行验证。

也可安全设置 `STUDIO_AI_API_KEY`，可选覆盖 `STUDIO_AI_BASE_URL`、`STUDIO_AI_MODEL`。浏览器只收到配置状态、域名与模型名。调用前确认发送记录，模型可能计费。云环境还需允许实际模型域名，保持代理与TLS校验，不绕过网络限制。

规则匹配按「能力标签覆盖75%＋待办预计工时余量25%」计算，是明确标注的规则，不是假称AI。岗位适配匹配已填能力和职位要求。建议由人工确认，不自动改派任务，不决定招聘或绩效，也不从年龄、性别等无关属性推断能力。

## 数据与边界

数据及头像保存于 `data/studio.sqlite`，可用 `DB_PATH` 覆盖。停止服务后备份整个data目录；首次升级补充配置并保留记录。示例项目、工时不代表实际投入。日期显示采用北京时间。重启环境后需重新启动进程。

**仍为内部共享试用版，尚无员工登录和身份权限控制。** 部门负责人、组长和交接确认记录协作职责，不验证操作者身份。仅在可信内部Wi-Fi试用；公网部署前需增加账号、权限、HTTPS、备份和审计。

暂未接入电商/自媒体API、通用文件上传、财务账本或成本计算。已有记录或下游引用会阻止直接删除。任务前置关系在创建时设置；模型结果保存为分析草稿，原始经验单独编辑保留。
