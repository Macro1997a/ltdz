# 铸序 · 工作室协作空间

面向铸造工艺品与首饰小团队的全流程管理 APP。第一版优先解决任务分工、截止日期和进度透明，按「工时＋完成数量＋成果链接」记录工作，不作绩效排名。

## 运行

需要 Node.js 24 或更高版本，无第三方运行依赖，无需 npm install。

```sh
cd /workspace/ltdz
npm start
```

默认监听本机 3000 端口。开发时可用 `npm run dev` 自动重启。测试使用 `npm test`，测试运行在独立的临时数据库，不影响试用数据。

如需在受控的内部网络访问，可设置 `HOST=0.0.0.0 PORT=3000 npm start`；必须由部署环境提供相应网络路由。浏览器连接同一个服务即可共享数据，通过 SSE 实时更新；断线自动重连并刷新数据。进程和 SSE 连接在环境重启后需要重新建立。

## 第一版功能

当前版本 v0.2。Windows 旧版用户请按 [更新步骤](UPGRADE-WINDOWS.md) 先备份并迁移整个 `data` 文件夹。

- 后台设置：一级分类与二级子分类的新增、编辑、停用和删除保护；项目自定义文字、数字、下拉字段，可指定适用分类、必填与排序；流程名称、排序、启用状态可维护。
- 个性化资料：昵称、简介、头像上传与移除；头像自动裁为512像素方形，服务端校验格式和2MB上限，保存到SQLite，不依赖外部图床。
- 手机布局：底部导航、大字号表单、任务卡片和可横向滚动的筛选，后台改动通过SSE实时同步到所有连接页面。

- 全局工作台：项目、进行中任务、3日内截止提醒、当日投入；统筹关注区汇总逾期、待交接确认、前置受阻，点击可查看相应任务。
- 个人任务：选择成员预览其待完成、待我确认、前置受阻、逾期和已完成任务，统计个人当日工时，并快捷填报工作。选择仅存于当前浏览器，不代表登录身份。
- 产品项目：新建项目、流程分布、详情与阶段更新；流程包括2D设计、3D设计、打样铸造、生产加工、宣发内容、上架销售。
- 任务协作：新建、负责人、预计工时、截止日期、状态更新、搜索与筛选。
- 团队与工种：新增、编辑、停用和重新启用成员；多选工种；工种新增、改名、停用；每人参考周工时可调，默认40h。保留历史引用，有未完成负责或交接任务时需先处理或重新分配，再停用。
- 工作记录：关联任务、成员、工作日期、工时、完成数量、说明及成果链接；不同工种数量不直接合并评分。

首次启动录入五人初始团队：杨彦杰（2D设计、3D制作）、张宏浩（3D制作、自媒体账号运营、产品规划）、岳普泽（3D产品拆件）、牟平（生产加工）、高洪剑（成本核算、生产进度对接、财务对账）。张宏浩初始承担统筹职责；每个人都可创建和分配任务，全员可查看全部项目与进度。统筹职责可在成员资料中调整，与工种分开。此职责标记暂不提供服务端身份权限控制。

同时生成演示项目与工作记录，界面明确标注「示例项目与工时」，不代表这些成员的真实投入。旧版默认名单会一次性迁移；已修改的成员资料及用户新增记录保留。产品封面是 CSS 示意图，不是真实产品照片。界面日期采用北京时间；初始化种子日期按服务器 UTC 生成。

数据保存在 `data/studio.sqlite`，可通过 `DB_PATH` 指定位置；该目录已从 Git 排除。重启保留数据，项目阶段由人员手动更新，不自动根据任务推断。备份请停止服务后复制整个 data 目录，或使用 SQLite 支持的在线备份方式。

## 当前边界与后续迭代

**这是共享演示原型，尚无员工登录、身份校验及权限控制，所有连接者均可填报或修改数据。请勿直接暴露到公网或填入敏感信息。** 公网部署需要先增加员工账号、权限、HTTPS、备份和审计，再部署到有持久存储的服务。当前没有执行公网发布，也没有接入真实电商、自媒体平台或文件上传；成果通过链接引用。

每个项目可设置「并行协作 / 交接确认 / 混合推进」，作为新任务表单的默认设置。实际规则按任务保存：不设前置任务即可并行，多项前置任务须全部完成才可推进；前置任务仅能选同项目已有任务，因此不会创建循环依赖。新建时可以设置是否需要交接确认及确认人。需要确认的任务提交「待确认」后，须通过指定确认人的交接操作完成，记录确认人和时间，再解锁下游。共享试用版未校验登录身份，所有使用者仍可代点确认，尚不构成权限控制或真实审批保障。下游已开始时，不允许直接撤回已完成的前置任务。任务详情支持调整负责人、交接确认人（完成前）与截止日期。

可编辑项目资料、分类和字段值，也可编辑任务名称、阶段和工时。未使用的设置项与空项目、无进展无记录无依赖的任务可删除，已使用的内容受到历史数据保护。后台字段当前作用于项目表单，任务前置关系尚不支持编辑；任务状态及协作方式仍采用现有业务规则。后续继续完善账号权限、任务评论与附件、通知、导出和部署。成本和财务先作为任务环节管理，尚无成本计算或账本模块。无需外部密钥。

## 验证

`npm test` 的14项测试覆盖原有协作流程，以及后台分类、自定义字段、流程改名、数据引用保护、头像上传与重启持久化、后台双客户端实时通知及旧数据库一次性升级保留原记录。Chromium另验证后台分类与子分类、动态字段联动、新增和编辑项目、真实图片上传、手机底部导航、任务卡片和任务编辑。服务默认绑定本机，若受沙箱限制无法监听，需使用平台允许的服务运行环境。
